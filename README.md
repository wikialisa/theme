# @wikialisa/theme

> Part of the [WikiAlisa](https://axvn.vn) UI component library.

## Installation

```bash
npm install @wikialisa/theme
# or
yarn add @wikialisa/theme
# or
pnpm add @wikialisa/theme
```

## Usage

```ts
import { version } from "@wikialisa/theme";
```
